Credit Card Customer Segmentation

Segmenting credit card users based on financial behavior using PCA and K-Means clustering

View Notebook Back to Portfolio

Overview

This project applies unsupervised machine learning techniques to segment credit card customers based on their spending patterns, credit usage, and repayment behavior. By transforming raw financial data into structured behavioral dimensions using Principal Component Analysis (PCA), the model identifies distinct customer groups with similar financial characteristics.

Key Insight

Customer behavior is driven by a combination of spending intensity, credit dependency, and repayment discipline rather than any single variable. The segmentation reveals clear groups such as low-activity users, high-value spenders, disciplined full payers, and high-risk credit-dependent customers, reflecting real-world financial behavior patterns.

Approach & Methodology

The analytical pipeline follows a structured unsupervised learning framework to guarantee robust, interpretable cluster boundaries:

  • Data cleaning and preprocessing
  • Exploratory data analysis (EDA)
  • Feature engineering & scaling
  • Principal Component Analysis (PCA) for dimensionality reduction
  • K-Means clustering implementation
  • Cluster interpretation and profiling

Future Improvements

To elevate this project further, upcoming milestones include validating clusters using additional statistical metrics, deploying an interactive cluster exploration dashboard via Streamlit, and building a real-time customer classification pipeline integrated with business decision systems.
