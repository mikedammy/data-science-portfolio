F1 Pit Stop Prediction

Predicting next-lap pit stop decisions in Formula 1 using machine learning

View Notebook Key Insight Approach

Overview

This project uses machine learning to predict whether a driver will make a pit stop on the next lap using Formula 1 race data. The model learns from race telemetry such as tyre wear, lap performance, and race context to identify patterns behind complex, high-stakes strategic pit decisions.

Key Insight

Pit stop decisions are primarily driven by performance degradation over time, particularly changes in lap time and tyre wear progression. Rather than relying heavily on static features like the initial tyre compound, the model successfully captures how active race performance evolves—closely reflecting real-world track strategy dynamics.

Approach

The project was executed through a structured data science lifecycle optimized for sports telemetry analytics:

  • Data cleaning and preprocessing
  • Exploratory data analysis (EDA)
  • Feature engineering (capturing temporal degradation dynamics)
  • Classification modeling

Future Improvements

To advance the accuracy and deployment value of the framework, upcoming phases will introduce SHAP (SHapley Additive exPlanations) values for structural feature interpretability, algorithmic hyperparameter tuning, and time-aware sequential modeling to capture real-time racing stints.
